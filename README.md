# Student Rewards — iPhone 17 Pro Max Campaign Web App

A high-converting, mobile-first web app concept for the **Student Rewards Campaign**, supporting instant verification, interactive UPI/QR/Card payment simulation, digital ticket generation, and status lookups.

## 🚀 Features
- **Mobile-First Experience**: Native bottom-sheet modals for iOS and Android, touch optimizations, and safe-area insets.
- **Warm Champagne Luxury Palette**: Vibrant Sunset Gold theme, glowing typography with Poppins & Montserrat, and ambient background light orbs.
- **Interactive Checkout Flow**: UPI apps (Google Pay, PhonePe, Paytm, BHIM), QR code scanner simulator, and Card options.
- **Digital Registration Pass**: Instant generation of unique registration IDs (`STU-XXXXXX`) with confetti celebration and WhatsApp pre-filled receipt links.
- **Registration Lookup**: LocalStorage persistence for checking registration status anytime (`MY STATUS`).

## 🛠️ Technology Stack
- HTML5 & Modern Vanilla CSS (Tokens, CSS Gradients, Glassmorphism, CSS Animations)
- Client-Side Vanilla JavaScript (ES6 Modules, Canvas Confetti)

## 📦 Deployment
Hosted on Vercel.
